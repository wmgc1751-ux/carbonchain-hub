### 3. 三个真实 bug（重要，别再踩）
1. **Vue 3 的 `h('x-card')` 不会查全局组件注册表** —— 字符串标签一律按原生元素处理，
   页面只剩骨架、内容区全空、**控制台没有任何报错**（生产版 Vue 不打解析失败警告）。
   → 解法：`core.js` 里提供组件名解析版 `h` 暴露为 `App.h`，各视图文件改为 `const h = App.h;`。
2. **路由参数没注入视图组件** —— `props.txId` 为 undefined，请求打到 `/chain/tx/undefined`。
   → 解法：应用外壳按 `Router.params` 注入 props，并用 `Router.path` 当 `key` 强制重挂载。
3. **冒烟脚本不幂等** —— 硬编码 2026/Q3 与业务唯一约束冲突。
   → 解法：先读已有上报单，自动挑空位周期；全满则 SKIP 而非 FAIL。

另外给 `server/app.js` 加了 `unhandledRejection` / `uncaughtException` 兜底，避免演示时被带崩。

### 6. 演示视频录制与两个真实 bug 的修复

**视频产出**：`artifacts/video/碳链通-系统运行演示.mp4`
- 17 幕 / 2 分 22 秒 / 1280×720 H.264 / 1.6 MB / 1596 帧（变帧率约 11.3fps）
- 画质已抽帧目视确认：真实渲染页面 + 底部中文分镜字幕条 + 模拟光标，非后期剪辑

**bug 1：ffmpeg concat 相对路径解析错了基准**
- 症状：`[concat] Impossible to open 'frames/f00001.jpg'` 后面跟一行
  `<frames.txt 的绝对路径>: No such file or directory` —— 这行报错**误导性极强**，
  让人以为清单文件丢了，实际是清单里的**帧**打不开。
- 根因：ffmpeg 的 concat 解析器按**进程 CWD**解析相对路径，不是按清单文件所在目录。
- 修法：concat 清单写绝对路径（反斜杠换 `/`），并给 spawn 传 `cwd`。
- 顺带给 `record-tour.js` 加了 `--encode-only`：复用已抓的帧重建清单只重编码，
  避免编码失败就要重录两分钟。

**bug 2：Edge 调试配置目录永久泄漏（本次清出 235MB）**
- 症状：`artifacts/` 下堆积 `.edge-profile/`、`.edge-profile-<时间戳>/`、`.edge-debug/`，
  每个 40~50MB，最大一次留了 5 个 + 1 个 debug 目录。
- 根因：`browser-check.js` 的 `killEdge()` 用 `setTimeout(1500)` 延迟删目录，
  而紧接着一行 `process.exit(0)` 把定时器一起掐掉，**删除代码从未执行过**；
  `record-tour.js` 压根没有删除逻辑，只 taskkill 进程。
- 修法（三个脚本统一）：
  1. 配置目录从 `artifacts/` 挪到 `os.tmpdir()/carbonchain-cdp/`，交付目录不再被污染；
  2. `killEdge` 改 async，`await` 真正删掉（3 次重试）后再退出；
  3. 加 `process.on('exit')` 兜底同步删除，异常路径也不漏。
- 验证：跑完整链路后 `artifacts/` 无 edge 残留，临时目录 profile 数 0 → 0。
