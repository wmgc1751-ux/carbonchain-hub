### ⚠️ 重要纠正：私钥删除不影响验签（之前判断错了）

我此前告诉你「删掉 keystore.json 会导致已有 918 笔存证验签失败」——**这是错的**。实测澄清：

- **验签用的公钥存在数据库**（`enterprise.pub_key` / `verifier_org.pub_key`），
  接口 `GET /api/chain/tx/:id` 从 `tx.pub_key` 取公钥验签，**完全不读 keystore.json**；
- 实测：删掉私钥启动后，签名校验仍返回 `signatureValid:true, payloadIntact:true`；
- keystore.json 的作用只是**签发时取私钥**，且是**按需懒生成**（`keystore.js: walletFor()` 里
  `if (!store[label]) { 生成并落盘 }`），所以删掉后启动不会重建，要等某主体首次签发才生成。

**结论：删除私钥零副作用，方案 A 完全可行。**

### 关键认知：「域名」在作业语境里的含义

作业原文「如果能够使用一些免费的服务器/域名来完成线上部署会更好」+ 截图「如果有单独域名，需在提交的时候写上」。
拆解为三层：

1. **必须的**：把系统真的跑到公网上；
2. **平台赠的**：Render 免费 Web Service 自动分配 `xxx.onrender.com` 二级域名
   （真实可公开访问的 HTTPS 域名，**无需自己买**）；
3. **纯加分**：自购独立域名（如 `carbon-chain.cn`），**可不做**。

→ 结论：拿到 `https://<name>.onrender.com` 即完全满足加分项要求。

### 顺带修掉真实缺陷：smoke-test 硬编码区块索引

**现象**：重建数据库后自检从 50/50 掉到 45/50，报「区块 #10 不存在」「交易不存在」「该上报单尚未上链存证」。

**根因**（两处，都是硬编码假设）：
1. `scripts/smoke-test.js` 写死 `/api/chain/blocks/10` 与 `blockIndex: 10`，但
   **`block_index` 并非从 0 连续编号**，重建链后索引 10 可能不存在；
2. 「链上存证详情」取上报单列表**第一条**，而第一条可能是**未上链**的草稿。

**修复**：
- 先调列表接口探测真实 `block_index`，再用它做详情/篡改/修复三处测试
  （注意：**列表返回库字段 `block_index`，详情返回转换后的 `index`**，别取错）；
- 上报单从列表里 `find(r => r.chain_tx_id)` 挑一条**已上链**的。

**验证**：连续跑两次均 50/50 全绿，且篡改目标自动变为当时的真实块号（如区块 #4 / #154）。
