## 一、作品摘要

**碳链通 CarbonChain Hub** 是一套面向工业场景的**联盟链碳资产动态核算可信存证平台**。它把工业物联网（IIoT）源端感知、温室气体核算（ISO 14064 / ISO 14067 / GB/T 24067）、不确定度量化、联盟链存证与碳资产交易打通成一条端到端可信链路，解决了当前企业碳核算「**数据不可信、核算不透明、存证不可验、口径不可质证**」四大痛点。

平台以**自研联盟链内核**（PoA 共识 + SHA-256 / 国密 SM2-SM3 双密码套件 + Merkle 树 + 五道链上链下校验）为信任根，以**真实公开数据源因子台账**（22 条官方出处、64 项因子/参数、可追溯率 98.4%）为核算基准，以**蒙特卡洛不确定度传播**（解析解 ↔ 抽样双向互证）为结果可信度度量，以**双轨对账**（组织碳 ⊇ 产品碳的包含性硬约束 + 存证覆盖率归因）为数据自洽判据。所有判据均经**负向注入验证（falsification）**证明非空。

| 维度 | 数据 |
| --- | --- |
| 链上存证 | 953 笔存证 / 163 区块（`npm run initdb` 基准），PoA 出块 0.55 ms（18,225 TPS） |
| 密码学 | SHA-256 130 万次/秒、SM3 85 万次/秒；SM2 与 GB/T 32905-2016 附录 A 逐位一致 |
| 因子台账 | 13 项燃料 IPCC 公式复算最大偏差 0.123%；A 级出处 34 项 |
| 不确定度 | 10000 次蒙特卡洛，解析解 ↔ 抽样相对偏差 0.06%（乘性链）/ 1.14%（加性） |
| 双轨对账 | 5 家企业、3 家接入计量，联盟存证覆盖率 14.93%，包含性全部成立 |
| 判据证伪 | 4 类故意破坏全部被检出 |

## 二、研发背景与痛点

全国碳市场已覆盖发电、钢铁、水泥、铝冶炼 4 行业 3680 家企业，年排放约 83 亿吨 CO₂（占全国 65%+）。欧盟碳边境调节机制（CBAM）已于 **2026-01-01 进入正式征收期**，对中国钢铁、铝等出口产品按缺省值法每吨额外征收 130~4670 元。但当前企业碳核算普遍存在：

1. **数据不可信** — 排放数据由企业自行填报，源端无硬件级可信采集，易被事后修改。
2. **核算不透明** — 用什么因子、走哪条算式、取哪个口径，都藏在 Excel 里，审计无法穿透。
3. **存证不可验** — 即便上了链，也只存一个哈希；链下原文改了，链上无感（本项目开发中实测踩到该漏洞并补上第五道校验）。
4. **口径不可质证** — 电网因子有「年均 0.5703」「电力碳足迹 0.6205」「区域基准线 OM/BM」多种口径，平台若只给一个数字，评审无法判断是否被混用。

**碳链通的解法**：把上述每一项都做成**可显式声明、可复核、可证伪**的工程对象。

## 五、关键技术与实现

### 5.1 自研联盟链内核（不依赖第三方链框架）

- **PoA 共识**：许可成员实名可追责，作恶撤销成员资格；出块成本 = 1 次 Merkle 建根 + 1 次区块头哈希 + 1 次出块方签名。实测 **0.55 ms/块、18,225 TPS**，比 PoW 难度 4（85.6 ms/块）快 155 倍。
- **双密码套件**：套件 A = SHA-256 + secp256k1/ECDSA（国际通用）；套件 B = SM3 + SM2（国密合规，GB/T 32905-2016 / GM/T 0004-2012）。SM3 官方测试向量逐位一致。**国密反而略快**：SM2 签 2099/s vs ECDSA 1889/s。
- **五道校验**（逐层递进）：① 区块头哈希重算 ② Merkle 根重算 ③ 出块方签名验签 ④ 交易签名验签 ⑤ **链下重算绑定**（payload 明文摘要 ≠ 链上锚定摘要即报警）。第五道是本项目开发中实测「链上四道对链下篡改无感」后补齐的，属原创加固。

### 5.2 核算算法与不确定度内核（App.Nucleus）

- **三档核算方法**：Tier 1 缺省因子法、Tier 2 国别参数展开法（NCV×CC×OF×44/12）、Tier 3 CEMS 连续监测。13 项燃料 Tier1/Tier2 对账最大偏差 **0.123%**（台账与其宣称的 IPCC 算式逐项自洽）。
- **蒙特卡洛不确定度传播**：乘性模型 y=Π xᵢ(1+σᵢzᵢ)、加性模型 y=Σ xᵢ(1+σᵢzᵢ)。解析解（误差传播律 √(Σσᵢ²)）与 10000 次抽样**相对偏差 0.06%**，互为独立验证。一阶敏感性用 corr(zⱼ,y)² 给出「该先测准哪一项」的可执行优先级。
- **双轨对账**：组织碳（ISO 14064-1，自上而下）⊇ 产品碳（ISO 14067，自下而上）。判据是**包含性硬约束**而非数值相等（试点期只存证部分批次，强行凑闭合才不可信）。声明核算期 92d×24h×在线率 11/12=2024 运行小时，未接入计量的企业显式排除不填补。

### 5.3 真实公开数据源因子台账（App.Sources）

- **22 条官方出处**：生态环境部、国家统计局、国家能源局、IPCC、国家气候战略中心、国家市场监督管理总局、欧盟官方公报等，每条带文号/公告号。
- **四口径电网因子隔离**：年均 0.5703（环办气候函〔2023〕43号）/ 电力 CO₂ 0.5568（2024 年第 12 号公告）/ 电力碳足迹 0.6205（2025 年 1 月）/ 七大区域基准线 OM/BM（NCSC 2024-07-08）。**严禁混用**，平台在 UI 上显式标注口径来源。
- **CBAM 合规映射**：欧盟明确排除绿证抵扣电力间接排放（criticalFact），只认可物理直连与 PPA；本平台对应「批次级 PCF + 第三方核查节点签名 + 设备 DID 上游数据可获取」五项能力映射。

**六项验证全部通过**：① 台账自洽 ② 产品碳三分量闭合 ③ 组织碳可核算 ④ 双轨包含性 ⑤ 判据可证伪 ⑥ 不确定度互证。

**判据可证伪性（falsification）** 是本作品的方法论核心：如果一条判据在任何输入下都通过，它就不是判据。本项目开发中真实踩到「链上四道校验对链下篡改无感」的坑（交易签名签 payloadHash、Merkle 叶由 payloadHash 派生后独立存储，故改链下明文不惊动链上锚点），补上第五道校验后才检出。4 类负向注入（篡改总量 / 改范围占比 / 删工序段 / 产品碳放大超组织碳）全部被检出。

## 八、落地价值与社会效益

1. **对企业**：一份 PCF 报告可同时满足国内碳市场履约、CBAM 申报、绿色金融质押三类场景，避免重复核查；接入计量后 Tier 2/3 可把不确定度从 ±15% 压到 ±5%。
2. **对核查机构**：链上签名背书 + 穿透式验真，把「核查报告可信度」从机构信誉升级为密码学可验证。
3. **对监管**：任意监管节点都能低成本全量复核整条链（1000 块校验 2.93 s，比构建还快），实现穿透式监管。
4. **对出口企业**：为 CBAM「实际值法」提供可被欧盟信任的数据链路，避免退回缺省值法的高额惩罚。

## 附录 A：预设答辩问答

**Q1：联盟链为什么不用以太坊？**
A：工业场景要求确定性时延与吞吐（PoA 0.55 ms/块、18k TPS），且许可成员实名可追责，作恶撤销资格即可，无需 PoW 的算力博弈。以太坊 Gas 费与时延都不适合工业级存证。

**Q2：链上只存哈希，链下原文改了怎么办？**
A：这正是本项目开发中实测踩到的坑。链上四道校验（区块头哈希、Merkle 根、出块签名、交易签名）对「只改链下 payload 正文」完全无感，因为交易签名签的是 payloadHash、Merkle 叶由 payloadHash 派生后独立存储。补上第五道「链下重算绑定」（明文摘要 ≠ 链上锚定摘要即报警）后检出。见 `/verify` 性能基准页的四类篡改检出对照。

**Q3：为什么双轨对账不要求组织碳 = 产品碳？**
A：组织碳刻画企业全部排放，产品碳只覆盖已存证的部分批次，两者口径本就不对等。强行凑闭合（如用 24×365 硬年化）是不可信的。正确判据是包含性硬约束（组织碳 ⊇ 产品碳）+ 存证覆盖率 ρ 如实报告。试点期 ρ=14.93% 是正常的。

**Q4：电网因子为什么有四个数字？**
A：四种口径分别对应不同核算标准，严禁混用：年均 0.5703（环办气候函〔2023〕43号，企业履约）/ 电力 CO₂ 0.5568（2024 年第 12 号）/ 电力碳足迹 0.6205（2025 年 1 月，生命周期口径）/ 区域基准线 OM/BM（CDM 项目减排量）。平台在 UI 上显式标注每个数字的口径来源。

**Q5：蒙特卡洛怎么证明自己算对了？**
A：与解析解（误差传播律 √(Σσᵢ²)）双向互证，相对偏差 0.06%（< 5% 自检闸门）。若偏差大说明抽样不足或模型非线性强，平台每次运行都校验，避免「跑了个蒙特卡洛但其实算错了」。

**Q6：国密是真的还是自己写的？**
A：不自研，全部调 Node.js 22 + OpenSSL 3.5.5 内置的 SM2/SM3 实现。SM3('abc') = 66c7f0f4…8e0 与 GB/T 32905-2016 附录 A 官方测试向量逐位一致，可判定为国标合规实现。
