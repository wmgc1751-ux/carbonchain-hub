### 2.3 开发目的（可直接复制）

> 针对工业企业碳排放核算中「数据不可信、核算不透明、存证不可验、口径不可质证」四类结构性问题，研发一套面向工业场景、以联盟链为信任根的碳资产动态核算与可信存证系统。系统打通工业现场计量设备的可信采集、温室气体多档核算、不确定度量化、联盟链共识存证与碳资产交易的全链路，使企业碳排放数据从「自行填报」变为「源头可采集、过程可复核、结果可证伪、历史可追溯」，为碳市场履约、产品碳足迹申报及出口碳边境调节机制（CBAM）申报提供可被第三方验证的数据基础。

### 2.4 主要功能（可直接复制）

> 1. 边缘感知与设备可信采集：以设备 DID 标识计量设备，模拟 TEE/SE 硬件签名并做物料平衡校验，异常设备自动阻断上链；
> 2. 多档核算内核：支持 Tier 1 缺省因子法、Tier 2 国别参数展开法、Tier 3 CEMS 连续监测三档方法；
> 3. 组织碳与产品碳双轨核算：分别按 ISO 14064-1 与 ISO 14067 / GB/T 24067 核算并做包含性对账；
> 4. 不确定度量化：蒙特卡洛抽样传播并以解析解双向互证，输出一阶敏感性排序；
> 5. 排放数据上报与第三方核查：企业端提交、核查机构端受理并出具报告，报告摘要上链；
> 6. 联盟链共识与存证：自研 PoA 授权证明共识、区块哈希链、Merkle 树、双密码套件与五道链上链下校验；
> 7. 联盟链成员治理：成员申请审批、授权出块、权重轮值、资格吊销与链副本同步；
> 8. 动态核算与履约风险预警：CEMS 读数按固定步长自动采集、滚动核算并自动生成履约风险预警；
> 9. 碳资产管理与抵销：碳配额账户与分配流水、碳信用资产登记与抵销（受配额比例上限约束）；
> 10. 碳配额交易撮合：挂单撤单、价格优先与时间优先连续撮合、冻结解冻、成交即上链；
> 11. 穿透式验真与数字护照导出：四级证据链核验与产品碳足迹数字护照导出；
> 12. 公示大屏与区块链浏览器：面向公众的数据公示与区块、交易、地址检索；
> 13. 科研验证中心：面向评审方的公开验证面板，含核算复算、不确定度互证、判据可证伪性与标准合规映射。

### 2.5 技术特点（可直接复制）

> 1. 密码学零第三方依赖：区块链内核基于 Node.js 内置 crypto 自研，未引入任何第三方区块链框架；
> 2. 国密合规双套件：同时支持 SHA-256 + secp256k1/ECDSA 与 SM3 + SM2，SM3 输出与 GB/T 32905-2016 附录 A 官方测试向量逐位一致；
> 3. 五道链上链下校验：区块头哈希重算、出块签名与授权资格、前向引用、Merkle 根重算、链下重算绑定；
> 4. 确定性可复现：随机数由固定种子驱动，跨机器复算结果逐位一致；
> 5. 判据可证伪：每项数据自洽判据均经负向注入验证，凡在任何输入下恒通过的判据不视为有效判据；
> 6. 前后端分离且无构建步骤：前端采用 Vue 3 CDN 全局构建，后端提供 REST 接口与 WebSocket 遥测通道。

## 四、在挑战杯申报中的使用

「挑战杯」全国大学生课外学术科技作品竞赛**科技发明制作类**的申报要求明确：
作品须为**以学生为第一完成人**的发明专利、实用新型专利（最少一项），**也可以是申请软件著作权**。

因此本材料包的作用是：

1. 以**学生为第一完成人**申请软件著作权（务必由学生本人作为著作权人提交申请，教师仅作指导）；
2. 取得《计算机软件著作权登记证书》后，作为申报材料的「支撑材料」附件提交；
3. 在《科技发明制作说明书》与答辩 PPT 中，将登记证书作为「自主知识产权」的硬证据引用。

> ⚠️ 两点务必注意：
> 1. **著作权人必须是学生本人**，不能登记在学校或教师名下，否则不符合竞赛「以学生为第一完成人」的要求；
> 2. 软著**审查周期通常 1～3 个月**，请按本校校赛截止日期倒排时间，尽早提交。

## 五、如何重新生成材料

源程序如有更新，可在项目根目录重跑生成脚本：

```bash
# 1) 重新生成源程序文档（60 页）与全文
node _gen_copyright.js

# 2) 重新生成软件说明书
node _md2pdf.js "碳链通CarbonChainHub/docs/软著申请材料/软件说明书.md" \
                "碳链通CarbonChainHub/docs/软著申请材料/软件说明书.html" \
                "碳链通联盟链碳资产动态核算存证系统 V1.0 软件说明书"

# 3) HTML → PDF（需本机安装 Microsoft Edge）
node _html2pdf.js "<输入 html 绝对路径>" "<输出 pdf 绝对路径>"
```

若需调整源程序收录顺序或软件名称，编辑 `_gen_copyright.js` 顶部的 `MANIFEST` 与
`SOFTWARE_NAME` / `VERSION` 常量即可。
