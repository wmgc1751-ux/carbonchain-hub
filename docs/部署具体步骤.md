# 阶段一（本机，5 分钟）把代码推到 GitHub

> 你已经完成的：git 仓库已建、96 个文件已提交、分支名 `main`、远程仓库**尚未配置**。
> 你还要做的：建 GitHub 仓库 → 配置远程 → 推送。

## 步骤 1：注册 / 登录 GitHub

浏览器打开 <https://github.com> → 右上角 `Sign up`（没有账号）或 `Sign in`（已有）。

- 邮箱建议用你常用的（如 QQ 邮箱）
- 用户名自己定，**记下它**，后面要用

## 步骤 2：创建空仓库

1. 打开 <https://github.com/new>
2. 「Repository name」填：`carbonchain-hub`
3. 可见性选 `Private`（私有）或 `Public` 都行 —— **私有更稳妥**
4. ⚠️ **下面三个勾全部不要勾**：
   - ❌ Add a README file
   - ❌ Add .gitignore
   - ❌ Choose a license
   （勾了会导致推送冲突，要多做一步 `pull --rebase`）
5. 点绿色按钮 `Create repository`

## 步骤 3：推送代码

创建完成后页面会显示仓库地址。打开 Git Bash（或 PowerShell），**逐行执行**：

```bash
cd "D:/workspace/MFAD/碳链通-CarbonChainHub-区块链碳数据存证与配额交易平台"
```

```bash
git remote add origin https://github.com/「你的GitHub用户名」/carbonchain-hub.git
```

> ☝️ **把 `「你的GitHub用户名」` 替换成步骤 1 里的用户名**，中文引号要去掉。
> 例：用户名是 `wang2026`，就填 `https://github.com/wang2026/carbonchain-hub.git`

```bash
git push -u origin main
```

推送时会**弹出浏览器登录窗口**（Git Credential Manager）→ 点 `Sign in with your browser` → 授权即可。**第一次推送会问一次，之后就不问了。**

# 阶段二（浏览器，10 分钟）创建免费云数据库

> 选 **TiDB Cloud Starter**：MySQL 协议兼容、免费额度足够、**不需要绑定信用卡**。

## 步骤 4：注册 TiDB Cloud

浏览器打开 <https://tidbcloud.com> → 点 `Sign Up`。

**推荐用 GitHub 账号一键登录**（最快，省掉邮箱验证）：
点 `Continue with GitHub` → 授权 → 完成。

> 若用邮箱注册：需要去邮箱点验证链接，然后再回来。

## 步骤 5：创建免费集群

登录后进入控制台：

1. 点 `Create Cluster`（或 `+ Create` → `Cluster`）
2. 集群类型选 **`Starter`**
   > ⚠️ **关键**：如果看到 `Zero` 或 `Serverless Trial`，**不要选**。
   > `Zero` 是 30 天过期的试用实例，交完作业就没了。要选 **`Starter`**（长期免费）。
3. 填写配置：
   | 字段 | 填什么 |
   | --- | --- |
   | Cluster Name | `carbonchain-db` |
   | Region | 选 `Oregon (US West)` 或 `N. Virginia (US East)` |
   | Root Password | **自己设一个强密码，立刻复制到记事本** |
4. 点 `Create` → 等待 1–2 分钟 → 状态变为 **`Active`**

## 步骤 6：记下连接信息（**最关键的一步**）

点集群名称进入详情页 → 点右上角 `Connect` 按钮 → 弹窗里选 `General` 或 `Node.js`。

**把下面 5 项抄到记事本，一项都不能错**：

| 界面上的字段 | 例（你的会不同） | 后面要用作 |
| --- | --- | --- |
| `Endpoint` / `Host` | `gateway01.us-west-2.prod.aws.tidbcloud.com` | `DB_HOST` |
| `Port` | `4000` | `DB_PORT` |
| `User` | `3pTAoNNegb47Uc8.root` | `DB_USER` |
| `Password` | （步骤 5 你设的） | `DB_PASSWORD` |
| `Database` | `test` | `DB_NAME` |

> ### ⚠️ 三个必须注意的坑（这一步最容易错）
>
> 1. **用户名必须带前缀**。界面给的是 `3pTAoNNegb47Uc8.root` 这样一长串，
>    **整串都要填**。只填 `root` 或只填前缀都会认证失败。
> 2. **端口是 `4000`**，不是 MySQL 常见的 3306。
> 3. **必须启用 TLS**，否则连不上（后面会设 `DB_SSL=no-verify` 解决）。

## 步骤 7：放行所有 IP（如果连不上再来做）

在集群详情页找 `Network` 或 `IP Access List`：

1. 点 `Add IP Address`
2. 填 `0.0.0.0/0`，说明写 `all`（允许所有 IP）
3. 保存

> 免费版通常默认就允许，**先跳过，连不上再回来做**。

## ✅ 阶段二验收

记事本上已经有 **5 项连接信息**，且你确认过：用户名是**带前缀的完整串**、端口是 **4000**。

## 步骤 10：如果报错，对号入座

| 报错 | 原因 | 怎么修 |
| --- | --- | --- |
| `Access denied` / `ER_ACCESS_DENIED` | 用户名或密码错 | 检查 `DB_USER` 是否**带了前缀**；`DB_PASSWORD` 有无多余空格 |
| `ENOTFOUND` | 主机名错 | `DB_HOST` 要**完整复制**，别带 `https://`、别带空格 |
| `ETIMEDOUT` / `ECONNREFUSED` | 端口错或 IP 未放行 | 确认端口是 `4000`；回**步骤 7** 放行 `0.0.0.0/0` |
| `SSL` / `certificate` 相关 | TLS 设置问题 | 确认 `cloud-db.env` 无需设 SSL（脚本已内置 `no-verify`） |
| `Unknown database` | 库名错 | `DB_NAME` 改成 `test` |

> 脚本会自动给出**针对性排查提示**。把完整报错发我，我帮你定位。

# 阶段四（浏览器，15 分钟）部署到 Render

## 步骤 11：注册 Render

浏览器打开 <https://render.com> → 点 `Get Started` / `Sign Up`。

**选 `GitHub` 登录**（会请求读取你的仓库权限，同意即可）。

## 步骤 12：创建 Web Service

1. 进入 Dashboard → 点右上角 `New +` → 选 **`Web Service`**
2. 选 **`Build and deploy from a Git repository`** → 点 `Next`
3. 首次会要求连接 GitHub → 点 `Connect GitHub` → 授权
4. 在仓库列表里找到并选中 **`carbonchain-hub`** → 点 `Connect`

## 步骤 13：填写服务配置（**逐项对照**）

| 界面字段 | 填什么 | 说明 |
| --- | --- | --- |
| **Name** | `carbonchain-hub` | ⭐ **决定你的域名** |
| **Region** | `Oregon (US West)` | 跟 TiDB 集群选同一个区域，延迟低 |
| **Branch** | `main` | 默认就是 |
| **Language** | `Node` | 通常自动识别 |
| **Build Command** | `npm install` | |
| **Start Command** | `npm start` | |
| **Instance Type** | **`Free`** | ⚠️ **必须选 Free**，别选 Starter（会扣费） |

> ### 🔑 关于域名（回答你的问题）
>
> 域名由 **Name** 字段决定：
> - Name 填 `carbonchain-hub` → 域名 **`https://carbonchain-hub.onrender.com`**
> - 若该名字被占用，Render 会提示改名，比如改成 `carbonchain-hub-2026`
>   → 域名随之变成 **`https://carbonchain-hub-2026.onrender.com`**
>
> 这是**平台免费赠的二级域名**，是真实可公开访问的 HTTPS 域名，
> **完全满足**作业「免费服务器/域名完成线上部署」的要求。**不需要自己花钱买域名。**

## 步骤 14：添加环境变量（**最关键，漏一个就起不来**）

在创建页面**不要点 Create**，先向下滚动到 **`Environment Variables`** 区域。

点 `+ Add Environment Variable`，**逐条添加下面 7 个**（Key / Value 一一对应）：

| # | Key | Value |
| --- | --- | --- |
| 1 | `DB_HOST` | 步骤 6 抄的 Host |
| 2 | `DB_PORT` | `4000` |
| 3 | `DB_USER` | 步骤 6 抄的完整用户名（**带前缀**） |
| 4 | `DB_PASSWORD` | 步骤 5 设的密码 |
| 5 | `DB_NAME` | `test` |
| 6 | `DB_SSL` | `no-verify` |
| 7 | `JWT_SECRET` | 自己敲一串随机字符，例：`cc-hub-2026-x9Kd83mQz7Lp4Rt6` |

> - `PORT` **不要设** —— Render 会自动注入
> - `HOST` **不要设** —— 代码默认就是 `0.0.0.0`，正是云平台需要的

# 附：可选加强项（不做也完全够）

## 附 A：防止免费实例休眠（推荐，5 分钟）

Render 免费实例 15 分钟无访问会休眠，答辩时可能遇到 30–60 秒冷启动。

1. 打开 <https://uptimerobot.com> → 注册免费账号
2. 点 `+ New Monitor` → 类型选 `HTTP(s)`
3. `URL` 填：`https://{你的域名}/api/health`
4. `Monitoring Interval` 选 **`5 minutes`**
5. 保存

这样每 5 分钟自动请求一次，实例保持唤醒。免费额度完全够用。

## 附 B：绑定自己的独立域名（需花几块钱，可选）

如果你**已经**有域名，或愿意买一个（阿里云/腾讯云首年常几十元）：

1. Render 服务页 → `Settings` → `Custom Domains` → `Add Custom Domain`
2. 输入域名，如 `carbon.carbonchain.cn`
3. Render 会给出 CNAME 目标：`carbonchain-hub.onrender.com`
4. 到域名服务商的 DNS 解析页，添加 CNAME 记录
5. 等 DNS 生效（几分钟到几小时），Render 自动签发免费 HTTPS 证书

完成后 `https://carbon.carbonchain.cn` 可访问，交作业时把这个域名一并写上（这是**加分项里的加分项**）。
