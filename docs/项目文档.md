# 项目文档（总入口） · 碳链通 CarbonChain Hub

> **面向工业场景的联盟链碳资产动态核算可信存证平台**
> 一句话：用联盟链给碳数据提供防篡改、可追溯、可第三方独立验证的可信层，并把碳核算从"季度人工填报"升级为"CEMS 准实时滚动核算"。

本文件是项目的**总入口**，汇总概览、导航、快速开始、实测结果与提交清单。各专题详见 `README.md` 与 `docs/`。

---

## 一、项目概览

| 项 | 内容 |
| --- | --- |
| 定位 | 联盟链（PoA）碳数据可信治理 + 碳资产动态核算 + 碳配额/碳信用交易 |
| 端 | 企业端 / 核查机构端 / 监管端 / 公众大屏 / 区块链浏览器（5 端） |
| 技术栈 | Node.js 22 + Express 4 / MySQL 8.0 / Vue 3.4 + ECharts 5.5（无构建） |
| 链内核 | 自研，零第三方区块链依赖（SHA-256 哈希链 + Merkle + secp256k1 ECDSA + PoA） |
| 数据规模 | 22 张表 / 29,385 行；链 163 区块 / 953 笔存证 |
| 接口 | 66 个 REST 接口 |
| 实测 | 接口自检 50/50 · UI 巡检 32/32 路由 + 5/5 交互 |

## 二、架构与链设计要点

```
Vue 3 单页应用（无构建）
   │ REST/JWT
Node.js + Express
   路由 → 服务层(anchor / trade / consortium / dynamic / credit)
        → 联盟链内核(crypto-utils / chain / keystore)
   │ mysql2
MySQL 8.0（链下业务 16 表 + 链上存证 2 表 + 联盟治理与动态核算 4 表）
```

**四个名实相符的关键点：**

| 标题关键词 | 落地实现 |
| --- | --- |
| **联盟链** | PoA 授权证明 + 5 成员节点准入白名单 + 按权重轮值出块 + 出块签名 + 多方链副本同步 |
| **碳资产** | 配额（可交易）+ 碳信用（CCER/碳汇/绿证，可抵销履约，≤ 配额 5%）|
| **动态核算** | CEMS 4 小时步长准实时采数 + 滚动累计 + 期末外推 + 配额缺口与履约风险预警 |
| **可信存证** | 哈希链 + Merkle（含存在性证明）+ ECDSA + 五道关全链校验 |

## 四、快速开始

```bash
npm install       # 安装依赖（仅 4 个）
npm run initdb    # 初始化：建库建表 + 造数 + 构建联盟链 + 动态核算自举（约 4 秒）
npm start         # 启动 → http://localhost:8300
```

Windows 用户可直接双击 `init-db.bat` 与 `start.bat`。

演示账号（口令见 README §7.3）：`admin` / `ent001`（企业）/ `ver001`（核查）/ `reg001`（监管）。

## 七、已知边界（诚实说明）

1. 各成员节点链副本仍与业务库同实例，未做跨机器 P2P 与网络分区容错；
2. 接口限流为进程内内存实现，多实例部署需改共享存储；
3. 业务数据以明文快照上链，真实场景宜改为"链上存哈希 + 链下加密"或零知识证明；
4. 无自动化测试 / CI、无容器化部署产物、无结构化日志与监控。

> 详见 `README.md` §九 与 `docs/部署说明.md`。
