# 数据留存策略（RR-06 · 2026-10-31）

## 分类分级与留存期

| 数据类 | 表 | 层级 | 留存期 | 依据 |
|---|---|---|---|---|
| 小时级实测读数 | cems_cn_hourly | **REAL（永不清理）** | 永久 | 省公开系统原始数据，平台真实性主张的基石 |
| 日均浓度 | cems_public_reading | REAL | 永久 | 部公开平台原始报文 |
| 排放核算值 | emission_calc / emission_report | DERIVED | 永久 | 履约与清缴依据 |
| 链上账本 | chain_block / chain_tx（3307） | PLATFORM | 永久 | 不可篡改性即业务 |
| 设备读数（模拟） | cems_reading | MODELED | 730 天 | 演练数据，超期可清 |
| 审计日志 | audit_log | 平台治理 | 365 天 | 与链上锚定互补，超期先归档后清理 |
| ZK 披露日志 | zk_disclosure_log | 平台治理 | 180 天 | 隐私最小化 |
| 接入日志 | data_ingest_log | 平台治理 | 180 天 | 排障后无用 |
| 通知公告 | notice | 公开内容 | 永久（发布制） | — |

## 执行

- 工具：`node tools/audit/retention-purge.cjs`（默认 --dry 只统计；`--execute` 实删）
- PROTECTED 名单硬编码于脚本（cems_cn_hourly / cems_public_reading / emission_calc / emission_report / chain_tx / chain_block 永不清理）
- 节奏建议：演示期不执行；产品化后每月执行一次并留执行记录

## 告警阈值（RR-09 配套 · /api/metrics）

| 指标 | 阈值 | 级别 |
|---|---|---|
| 5xx 率 | >1% 持续 5min | P1 |
| P95 延迟 | >500ms 持续 10min | P2 |
| DB 连接失败 | 即时 | P0 |
| 链高度停更 | >30min | P2（演示期调度为 24h 锚定时除外） |
